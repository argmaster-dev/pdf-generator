# Установка на Windows

## Проблема с WeasyPrint

WeasyPrint требует GTK+ библиотеки, которые не входят в стандартную установку Python на Windows.

## Решение 1: Установка GTK+ через установщик (рекомендуется)

1. Скачайте установщик GTK+ для Windows:
   - Перейдите на: https://github.com/tschoonj/GTK-for-Windows-Runtime-Environment-Installer/releases
   - Скачайте последнюю версию (например, `gtk3-runtime-3.24.31-2021-01-30-ts-win64.exe`)

2. Запустите установщик и следуйте инструкциям

3. **Важно:** После установки:
   - Закройте все окна терминала/IDE
   - Откройте новый терминал
   - Активируйте виртуальное окружение
   - Попробуйте запустить скрипт снова

## Решение 2: Установка через MSYS2

1. Установите MSYS2: https://www.msys2.org/

2. Откройте MSYS2 terminal и выполните:
   ```bash
   pacman -Syu
   pacman -S mingw-w64-x86_64-gtk3
   ```

3. Добавьте путь к GTK+ в переменную окружения PATH:
   - Обычно это: `C:\msys64\mingw64\bin`

## Решение 3: Использование conda

Если у вас установлен Anaconda или Miniconda:

```bash
conda install -c conda-forge weasyprint
```

Это автоматически установит все необходимые зависимости, включая GTK+.

## Проверка установки

После установки GTK+ попробуйте запустить:

```bash
python pdf_generator.py
```

Если вы видите меню с выбором файлов - всё работает! ✅

Если ошибка сохраняется:
1. Убедитесь, что вы перезапустили терминал после установки GTK+
2. Проверьте, что GTK+ добавлен в PATH (для MSYS2)
3. Убедитесь, что версия Python (32-bit/64-bit) соответствует версии GTK+

## Альтернатива: Docker (для продвинутых пользователей)

Если установка GTK+ вызывает проблемы, можно использовать Docker:

```bash
docker run -v "%cd%":/app -w /app python:3.11 python pdf_generator.py
```

Но для этого потребуется установленный Docker Desktop.
